# Architecture decision records

Decisions that shape this repo's structure, interfaces or process are recorded here as numbered ADRs, copied from [0000-template.md](0000-template.md).

- Write an ADR when a change adds or replaces a dependency, a public interface, a data format, a boundary between modules, or a process rule.
- Name files `NNNN-short-title.md`. Never edit an Accepted ADR's decision; supersede it with a new one.
- Every PR states its decision record under "Decision record" in the PR template: an ADR link, or "none needed".
